# 🎄 Advent of Code Solutions

Solutions for past, present, and future [Advent of Code](https://adventofcode.com/) challenges.

## 📂 Repository Structure

The repository is organized by year:

```text
├── 2015/
├── 2016/
├── 2017/
├── ...
└── 2026/
```

Each directory contains puzzle solutions, inputs, and helpers for that specific year's events.

## 🌟 About Advent of Code

[Advent of Code](https://adventofcode.com/) is an annual Advent calendar of small programming puzzles for a variety of skill sets and skill levels that can be solved in any programming language you like.
